# 项目管理知识库

> **项目根节点** · 本知识库的唯一入口与导航中枢

本页是项目管理知识库的根节点：所有项目文档、决策、会议纪要与执行记录都从这里展开。新增内容请挂到对应子节点，并回链到本页，避免知识散落。

| 字段 | 值 |
| --- | --- |
| 节点类型 | 项目根节点 |
| 知识库名称 | 项目管理知识库 |
| 状态 | 已建立 |
| 维护原则 | 先更新根导航，再写子页 |

---

## 概述

用一套固定结构管理项目全过程：目标与范围、里程碑、任务执行、风险与决策。根节点只负责**定义结构、指向子页、汇总当前状态**，不承载长篇细节。

当前仓库 `menb` 以本知识库作为项目管理的单一事实来源（Single Source of Truth）。

---

## 目标

- 建立可检索、可回溯的项目管理知识体系
- 让目标、进度、风险、决策都能从根节点一跳到达
- 新成员通过根节点即可理解项目全貌与工作方式

| 风险 | 影响 | 缓解 |

## 使用约定

1. **只从根节点生长**：新文档先在「知识导航」登记，再创建子页。
2. **根节点保持短**：状态用表格，细节写在子节点。
3. **子页必须回链**：每个子页顶部保留指向本根节点的链接。
4. **变更可追溯**：重要取舍写入 [决策记录](./06-决策记录.md)，不要只改正文。
