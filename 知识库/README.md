## 阶段门禁

过门只做检查，不复制知识库。全部通过才切换「当前阶段」。

| 门禁 | 通过条件（核对领域页，不建新目录） | 状态 |
| --- | --- | --- |
| 启动 → 规划 | 总览有背景与干系人；目标与非目标已写；本阶段关键决策已入决策记录 | 未通过 |
| 规划 → 执行 | 范围已冻结或明确变更规则；近期里程碑与任务已列出；风险已评审 | 未开始 |
| 执行 → 收尾 | 里程碑交付可核对；未关闭风险已处置或移交；变更均有决策记录 | 未开始 |
| 收尾完成 | 总览改为最终状态；教训写入会议或决策；开放风险已关闭或移交 | 未开始 |

## 概述

用知识领域管理**知识放哪**，用生命周期管理**现在该更新哪几页**。根节点只负责整合：阶段状态、领域导航、未关闭项。长篇细节写在对应领域子页。

当前仓库 `menb` 以本知识库作为项目管理的单一事实来源（Single Source of Truth）。

---

## 目标

- 建立可检索、可回溯的项目管理知识体系
- 让目标、进度、风险、决策都能从根节点一跳到达
- 新成员通过根节点即可理解项目全貌与工作方式
- 阶段切换只改本页状态与门禁，不拆、不迁领域目录

## 使用约定

1. **先定领域，再标阶段。** 新文档先归入范围 / 风险 / 决策等，再标注它属于哪一阶段的产出。
2. **只从根节点生长。** 新文档先在「知识导航」登记，再创建子页；禁止新建「启动/规划/执行」目录。
3. **根节点只做整合。** 生命周期状态、领域导航、未关闭项放在本页；细节写在领域子页。
4. **子页必须回链。** 每个子页顶部保留指向本根节点的链接。
5. **阶段结束只过门，不迁树。** 切换阶段时只更新本页状态与门禁表，不把子页搬到阶段文件夹。
6. **变更可追溯。** 重要取舍写入 [决策记录](./06-决策记录.md)，不要只改正文。
