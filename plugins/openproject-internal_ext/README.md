# openproject-internal_ext

OpenProject **12.5.8** 企业内部插件（GPLv3）。不修改上游核心文件，不升级主版本。

| 命名空间 | 能力 |
| --- | --- |
| 本土化 | zh-CN 覆盖、CJK、默认语言 |
| 资源负载 | 全局热力图、冲突预警、排班/节假日、利用率导出 |
| EVM 成本 | 物料/外包/差旅/杂费 + PV/AC/EV/SPI/CPI/EAC，不替代原生 costs/budgets |
| 甘特流程 | CPM、基线、依赖顺延建议、立项到复盘模板 |
| 报表 | 进度复盘 / 人力成本 / 资源利用率（UTF-8 CSV） |
